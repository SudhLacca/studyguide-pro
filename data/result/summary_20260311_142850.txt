A recent survey found that 61% of lending organizations identified themselves as victims of document fraud, with 42% involving fraudulent documents with alterations in financial details and 50% with identity details altered.</div><div style='margin-bottom: 16px; font-weight: 500; color: inherit;'>To address this issue, a novel and hybrid technique for forgery detection is proposed using Convolutional Neural Networks (CNNs). The method treats forgery detection as an image segmentation task, leveraging the skills of CNNs to correctly identify and delineate suspicious regions within any type of document.</div><div style='margin-bottom: 16px; font-weight: 500; color: inherit;'>The proposed method employs hybrid multi-task learning, which combines image and text-based forgery detection. This approach enables the model to detect sophisticated forgeries and provides broader context to learn patterns related to both text and forgery.</div><div style='margin-bottom: 16px; font-weight: 500; color: inherit;'>The method uses a pre-trained text detection model to create additional labels for the dataset, easing the pains in data preparation and utilizing advanced models for augmenting the dataset. The main forgery detection model is enriched with this text detection label inclusion, providing more accurate and robust detection results.</div><div style='margin-bottom: 16px; font-weight: 500; color: inherit;'>The proposed method has several advantages, including:</div><div style='margin-bottom: 16px;
