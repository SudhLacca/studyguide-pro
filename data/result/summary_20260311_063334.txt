<div style='margin-bottom: 16px; font-weight: 500;'>Document Forgery Detection using Hybrid Multi-task Learning and Integrated Expert Labels</div><div style='margin-bottom: 16px; font-weight: 500;'>A robust document forgery detection model has been developed using Convolutional Neural Networks (CNNs) and multi-task learning. The model can detect both image and text-based forgeries and segment a document into meaningful parts for accurate analysis. The model's ability to detect sophisticated forgeries is enhanced by multi-task learning, which enables it to run multiple tasks simultaneously.</div><div style='margin-bottom: 16px; font-weight: 500;'>The model relies on both images and text to detect tampered visual parts and identify text anomalies. It segments a document into meaningful segments for more accurate analysis, especially when differences between the original and forged parts are minimal. The model also provides adequate accuracy for fine-grained manipulations at low resolutions or degraded images.</div><div style='margin-bottom: 16px; font-weight: 500;'>The model's shared learning among tasks helps develop computational efficiency and scalability, making it suitable for high-volume applications in finance and government sectors. The model promotes cross-model learning abilities across different document formats, resolutions, and layouts.</div><div style='margin-bottom: 16px; font-weight: 500;'>To improve the model's performance, an auxiliary task is incorporated using a pre-trained text detection model. This expert model produces bounding boxes on text regions in receipt images, which are subsequently used to create additional labels for the dataset. The inclusion of text detection labels enriches the training information for the main forgery detection model, providing broader context to learn patterns related to both text and forgery.</div><div style='margin-bottom: 16px; font-weight: 500;'>Research is still needed to reduce distortion effects and cross-domain generalization. Incorporating an auxiliary task, such as Optical Character Recognition, can add another layer of validation, especially for numerical data like receipts. Additionally, using deep learning models like GANs to simulate forgery techniques can widen the datasets and expose the model to various forgery types.</div><div style='margin-bottom: 16px; font-weight: 500;'>The detection process can be explained through combination with XAI techniques, providing transparency and insights on why a certain area has been classified as forged.
